# Le carnet de camille

Site Zola d'exemple accompagnant le livre *NixOS : Le système
déclaratif* — deux pages, sans thème, volontairement minimal.

Le livre vous invite à l'*adopter* : cloné puis délesté de son
historique, il devient le contenu de votre propre dépôt, que votre
recette `mon-blog.nix` empaquette. Sans le livre, ce dépôt se lit
comme un squelette : c'est lui qui porte le contexte.

Détail de facture : `base_url = "/"` — les liens sont calculés
racine-relatifs, le site fonctionne à n'importe quelle adresse qui
le sert à sa racine.
